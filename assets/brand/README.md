# Бренд Shotly

Утверждено 07.11.2026.

## Знак и логотип

| Файл | Где использовать |
| --- | --- |
| `shotly-mark.svg`, `shotly-mark-1024.png` | Основной знак без подложки |
| `shotly.ico` | Иконка приложения (16–256 px). Копия лежит в `src/Shotly/Assets/Shotly.ico` |
| `tray/shotly-tray-dark.*`, `tray/shotly-tray-light.*` | Только для трея: упрощённый знак на всё поле, кадры 16–64 px. Копии в `src/Shotly/Assets/TrayDark.ico` и `TrayLight.ico` |
| `shotly-tile.svg`, `shotly-tile.ico`, `shotly-tile-1024.png` | Знак на тёмной подложке: установщик, магазин приложений |
| `shotly-avatar-dark.*`, `shotly-avatar-light.*` | Аватары соцсетей (знак помещается в круглую обрезку) |
| `shotly-mark-white.*` | Белый знак поверх фото и цветных баннеров |
| `shotly-logo-horizontal-on-light.*`, `shotly-logo-horizontal-on-dark.*` | Основной логотип с надписью |
| `shotly-logo-vertical-on-light.*`, `shotly-logo-vertical-on-dark.*` | Логотип для квадратных мест |

Надпись в логотипе переведена в кривые, шрифт для неё устанавливать не нужно.

Вокруг знака оставляйте пустое поле не меньше четверти его ширины. Знак без надписи — от 16 px, с надписью — от 24 px по высоте знака.
Нельзя менять цвета половин, растягивать, поворачивать, добавлять тени и ставить знак на оранжевый или янтарный фон.

## Значок в трее

В трее знак крошечный и стоит вплотную к чужим значкам, поэтому для него сделан отдельный глиф:
без полей, половины чуть толще, зазор между ними шире (~1.8 px при 16 px), каждый размер отрисован
отдельно. Цвета чуть сдвинуты для контраста: на тёмной панели `#FF5A1F` / `#FFB81A`,
на светлой `#E8460C` / `#F09A00`. Приложение само выбирает вариант по теме Windows.
Пересобрать: `python tools/make_tray_icons.py` (нужны numpy, scipy, Pillow).

## Цвета (палитра Ember)

| Название | HEX | Для чего |
| --- | --- | --- |
| Ember | `#F2541B` | Верх знака, кнопки, главный акцент |
| Amber | `#FFB000` | Низ знака, подсветки на тёмном. Не для текста на светлом |
| Coal | `#1C1917` | Тёмный фон, подложка, основной текст |
| Cream | `#FFF7ED` | Светлый фон |
| Ember Deep | `#C2410C` | Ссылки и акцентный текст на светлом фоне |
| Ash | `#78716C` | Подписи и второстепенный текст |

## Шрифты

- **Unbounded** (Bold, трекинг −2%) — надпись логотипа и заголовки.
- **Onest** — текст на сайте, в постах и документах.
- В самом приложении остаётся системный **Segoe UI**.

Оба шрифта бесплатные (лицензия OFL), с кириллицей: https://fonts.google.com/specimen/Unbounded, https://fonts.google.com/specimen/Onest

## В приложении

- Цвета и шрифты для кода: `src/Shotly/UI/Brand.cs`, стили контролов: `src/Shotly/Themes/Shotly.xaml`.
- Шрифты Onest (текст) и Unbounded (заголовки) встроены в exe из `src/Shotly/Assets/Fonts` (лицензия OFL, тексты лицензий рядом). Если шрифт не загрузится, Windows подставит Segoe UI.
- Рамка выделения и выбранный инструмент — Ember, подсказки клавиш и кольцо выбранного цвета — Amber, панели, меню трея и уведомления — Coal.
- Значки рисуются вектором (`src/Shotly/UI/Icons.cs`), иконочные шрифты Windows не используются.
